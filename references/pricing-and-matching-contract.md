## 一、标准 15 列工作簿输出架构（写死，严禁偏移）

目标工作表默认 `门店商品`（若不存在则取活动工作表）。**`A ~ G` 列绝对只读保护，严禁修改原值或移动行号**。

| 列 | 列名 | 权限 | 强制写入格式与校验规则 |
| :---: | :---: | :---: | :--- |
| **A** | `SPUID` | 🔒 只读 | 门店商品 SPU 编码 |
| **B** | `SKUID` | 🔒 只读 | **写回锁行主键**：`step4_apply_and_export.py` 强制校验 `decisions.json` 中的 `skuid` 与 `B{row}` 完全一致，否则中止写入 |
| **C** | `分配人` | 🔒 只读 | 仅清理历史误写入的 `http...` 图片 URL；其他文本严禁修改 |
| **D** | `商品名称` | 🔒 只读 | 门店商品原始全称 |
| **E** | `规格名称` | 🔒 只读 | 门店原始销售规格 |
| **F** | `当前原价` | 🔒 只读 | 门店零售价（毛利率计算基准） |
| **G** | `主图链接` | 🔒 只读 | 门店官方主图 URL |
| **H** | `供货商品链接` | ✏️ 写入 | 命中填干净链接：`https://detail.1688.com/offer/{oid}.html` 或 `https://mobile.yangkeduo.com/goods.html?goods_id={gid}`；组合/生鲜分别填 `组合商品` / `生鲜蔬果本地采购` |
| **I** | `供货规格` | ✏️ 写入 | **【零备注逐字节强约束】** 100% 逐字照抄供货商页面真实可选 SKU 原文，**一个字/符号/空格都不能差**，绝对禁止添加 `(包邮)`、`起批`、`券后`、`百亿补贴`、`店铺优惠`、`大促直降`、`颜色随机同价`、品牌前缀或 `A+B=1套` 等任何人工备注！1688 双层严格用英文分号+空格 `; `（禁止 ` / `），无规格单品填 1688 完整官方标题 `offerTitle`，3 层/多空格直接取底层 `skuInfoMap` 原始键；拼多多同样严禁追加券后/补贴/大促注释，双层用 `; ` |
| **J** | `结算链接` | ✏️ 写入 | 1688 同 `H` 列；拼多多填免拼收银台直达链或同 `H` 列详情链 |
| **K** | `下单比例` | ✏️ 写入 | 供货单笔采购对应的**门店基础销售单位份数**（正数，整数优先；例如门店卖 `100抽*1包`、拼多多买 `6包整提` → `K=6`） |
| **L** | `采购价` | ✏️ 写入 | 供货单笔采购实付总价（浮点数，保留两位小数；1688 含分摊运费，拼多多按最新常规券后到手价） |
| **M** | `单位采购价` | ✏️ 公式 | **强制写入 Excel 公式**：`=ROUND(L{row}/K{row},2)`（禁止写死静态数值） |
| **N** | `是否匹配` | ✏️ 枚举 | **强制枚举值（严禁自造状态文本）**：见下方状态枚举表 |
| **O** | `供货商主图` | ✏️ 写入 | **1688 行必填**无缩略后缀高清 CDN URL（`https://cbu01.alicdn.com/img/ibank/...jpg`）；**拼多多行留空**（严禁残留旧 1688 CDN 图链；由 `export_visual_audit_html.py --pdd-img-dirs` 自动内嵌本地实拍头图） |

### N 列（是否匹配）唯一合法状态枚举

| 状态值 | 判定条件 | 说明 |
| :--- | :--- | :--- |
| `已核可采购` | 视觉验真同款 + 门店售价 `> 0` + `1 - (L/K)/F ≥ 50%` | 达标可采购 |
| `已核同款(毛利<50%)` | 视觉验真同款 + 门店售价 `> 0` + `1 - (L/K)/F < 50%` | **必须同步入表**，不得丢弃 |
| `已核同款(售价为0)` | 视觉验真同款 + 门店原价为 `0` 或空 | 同步入表，不判毛利 |
| `组合商品` | 多品/整箱组合装（如牛奶整箱组合、多品捆绑装） | 免找链接，`H/N` 填 `组合商品`，`I..M/O` 留空 |
| `生鲜蔬果本地采购` | 鲜活生鲜果蔬肉禽蛋水产 | 免找链接，`H/N` 填 `生鲜蔬果本地采购`，`I..M/O` 留空 |
| `不匹配` | 人工核对判错或双平台确实无在售同款待确认 | 保留原样并列入待拍板清单，严禁硬塞错品 |
| `未匹配` | 尚待检索或已确认无在售货源 | 同上 |

## 二、拼多多与 1688 强制核价口径

### 1. 拼多多核价铁律（用户最新终版口径）
- **必须计入（使用扣减后的真实到手价）**：
  - `店铺优惠`（含 `店铺优惠-X元`、`店铺新客立减`、`限1件` 常规店铺立减）
  - `店铺券`、`无门槛券`（店铺无门槛券）、`关注券`、`直播券`
  - `百亿补贴`、`官方补贴`、`百亿加倍补`、`万人团价`、`平台券`、`大促直降`、`限时直降`、`限量低价`、`凑单团价`
- **禁止计入（严禁扣减）**：
  - 仅限于买家账号个人的**拼多多无门槛红包**（新用户首单红包、客诉赔付红包、多多果园个人红包等）不得计入采购成本。
- **强制一票否决**：
  - 标题/SKU 含 `临期`、`过期`、`已抢光`、`该款式售罄` 的选项严禁选用。
  - **禁止单瓶/单包高价陷阱**：吃喝、洗护、纸品、调料等标品若存在 `6/12/24` 整箱或多件装且单价更优，必须选整箱/多包装，严禁只拍 1 瓶把 3 元邮费算进单价。

### 2. 1688 核价铁律
- **双层 SKU 必须二次点击**：当 `options` 非空且目标选项不是 `options[0]` 时，必须调用 `step2_1688_search.py --mode detail` 并传入 `"option"` 静默点击后读取真实行价，严禁拿默认首项价格充数。
- **表格型 SKU 防粘连核对**：部分 1688 页面 `sku_txt` 会把价格和库存拼在一起（如 `¥5.8` + 库存 `3` 变成 `¥5.83`），必须与 `main` 价格区间交叉核对。
- **防挂羊头卖狗肉**：必须检查 `attrs`（品牌、类目、发货周期）；若主图是大牌但 `attrs` 写 `品牌: other`、错类目（如主图牛奶、属性豆干）或 `30天发货`，一律一票否决。
- **高销源头优先**：同类同模具商品优先选择累计销量几千至 10 万+、回头率高、包邮或小件平摊运费低的源头工厂，避免选低销高价二道贩子。

## 三、多模态匹配与包装对齐规则（已获业务确认）

### 1. 允许放行的 6 条业务容差规则
1. **忽略服装/内裤体重建议文案**：如 `建议 80-100 斤` 等提示文案差异不作为不匹配依据，以尺码/品类/材质为核心。
2. **允许非核心属性/包装微差**：新老包装迭代、轻微图文改版、非核心配件赠品差异（赠品不计入 `K` 份数）允许放行。
3. **允许随机色五金/香皂花近似**：门店标“颜色随机”的日用五金允许同模具通用色；礼盒装饰花束允许同造型香皂花近似。
4. **允许厂方微幅减重/改克重**：品牌方统一迭代后的现行小幅克重调整（如 30g→28g、24g→20g 现行厂规）允许放行。
5. **组合商品直接标注**：标 `组合商品`，无需找采购链接。
6. **生鲜蔬果直接标注**：标 `生鲜蔬果本地采购`，无需找采购链接。

### 2. 严禁触碰的匹配红线
- **严禁张冠李戴/白牌冒充品牌**：门店明确写品牌的商品（如得力、全棉时代、九阳、味滋源、蒙牛、海天等），严禁用白牌或他牌冒充。
- **严禁大小规格强行错配**：如门店卖 `25g/包` 便利店迷你装而全网仅有 `120g/袋` 或 `60g/袋`，不得硬填；应保留待确认并在交付报告中列出官方在售最小规格供用户拍板。
- **严禁单片错算（基础包装语义对齐）**：
  - 门店卖 `100抽/包` 洗脸巾，供货卖 `100抽*6包` → **`K = 6`**（绝不是 `600`！）。
  - 门店卖 `100支/盒` 棉签，供货卖 `100支*10盒` → **`K = 10`**（绝不是 `1000`！）。
  - 门店卖 `30个/包` 元宝纸，供货卖 `1袋30个` → **`K = 1`**（绝不是 `30`！）。
  - 尺寸长宽（如 `40*30*30cm`、`25*25cm`）绝对不是包装数量。

## 四、平台第一轮硬锁与二轮回退契约（v3.4 新增）

1. **食品与快消品第一轮锁死拼多多（`platform_policy = "pdd_first_lock"`）**：
   - 涵盖：休闲食品、饮品/饮料、速食/罐头、粮油调味干货、营养冲调、酒水茶叶，以及洗护、护肤美妆、纸品/洗脸巾/湿巾、卫生巾、家清洗衣液、母婴纸尿裤、宠物食品等快消品。
   - **第一轮严禁直接搜 1688、严禁沿用历史表旧 1688 链接、严禁直接从牵牛花 1688 缓存抄近道入表**。
2. **第二轮有条件放行 1688**：
   - 仅当第一轮已完成拼多多真机实搜（磁盘存在非阻断的 `pdd_*/R{row}.json`），且满足以下任一业务条件时，方可转 1688 补找：
     - `"pdd_no_match"`：拼多多实搜无相似/可售同款（含异牌、临期、限购 1 件、断货、分区限购）；
     - `"pdd_low_margin"`：拼多多有同款，但实付单价毛利 `< 50%` 或价格倒挂（若同时填写 `pdd_best_unit_price`，代码强制校验毛利确实 `< 50%`）。
   - `step2_1688_search.py`、`step4_apply_and_export.py`、`step4_yuandian_push.py` 均内置物理阻断闸门，无绕过开关。
