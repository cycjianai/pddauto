# 基础销售单位与多层级包装语义对齐详细规范 (Unit Alignment Specification)

## 1. 业务背景与风险警示
在 1688 与拼多多的货源库中，商品规格的命名存在大量“层级嵌套”或“营销大数字”现象。
例如：
- 洁面巾标“240片（3包）”，甚至只标“240片”；
- 婴儿棉签标“600支【3盒装】”或直接标“600支”；
- 功能饮料标“250ml*24罐整箱”；
- 电池标“20节”；
- 菜板标“20*30cm（赠100只自粘袋）”。

如果简单的以数字作为除数，或者把供货商的每一“片/支/抽”当成门店的销售单位，将导致采购单价计算产生致命偏差（将原本 ¥4.00/包 的洗脸巾算成 ¥0.08/片，造成巨额亏损）。

## 2. 门店销售单位提取 (Store Pack Details)
从门店端抓取的名称与规格，解析以下属性：
- `isDurable`: 是否为耐用品（菜板、剪刀、锅、杯、数据线、收纳盒等）。耐用品不参与内含片数换算。
- `innerCount`: 包装内含最小离散件数（如 80片、60抽、200支、2节）。
- `innerUnit`: 离散件数单位（片、抽、支、节、枚、粒）。
- `outerCount`: 门店售卖的外包装数量（通常为 1包、1盒、1罐，极少为 2包组合）。
- `outerUnit`: 外包装单位（包、盒、袋、提、罐、瓶、桶、卷、卡、副、双）。

## 3. 供货商规格提取 (Supplier Pack Details)
对 1688/拼多多的 SKU Spec 文本进行预处理：
1. 过滤尺寸表达式（如 `20*30cm`、`100*30` 等，防止长宽被误认为件数）。
2. 过滤促销干扰词（`买2送1`、`赠30只`、`带提手`）。
3. 识别显式单包（`1包`、`单包`、`1盒`、`120片/包`、`装*1`）。
4. 提取复合包装结构（如 `3包【共240片】` $\rightarrow$ outerCount=3, innerTotal=240）。
5. 提取独立大片数（如 `240片` $\rightarrow$ innerTotal=240）。

## 4. 换算比率 $N$ 计算决策表

| 场景 | 门店特征 | 供货商特征 | 换算比率 $N$ 计算公式 |
| :--- | :--- | :--- | :--- |
| **耐用品保护** | isDurable = true | 含有附赠散件（如100只塑料袋） | $N = 1$ |
| **显式单包装** | 任意 | 标明“单包/1包/1盒/单件” | $N = 1$ |
| **双向含片数** | innerCount = 80片 | 标明“3包”或“3包共240片” | $N = \max(1, \mathrm{round}(3 / 1)) = 3$ |
| **供货商仅大片数** | innerCount = 80片 | 仅标明“240片” | $N = \max(1, \mathrm{round}(240 / 80)) = 3$ |
| **供货商超大片数** | innerCount = 80片 | 标明“480片” | $N = \max(1, \mathrm{round}(480 / 80)) = 6$ |
| **双向含支数** | innerCount = 200支 | 标明“600支” | $N = \max(1, \mathrm{round}(600 / 200)) = 3$ |
| **纯外箱整箱** | 250ml*1罐 | 标明“250ml*24罐整箱” | $N = \max(1, \mathrm{round}(24 / 1)) = 24$ |
| **成双品散只** | 1双/对 | 标明“1000只散装” | $N = \max(1, \mathrm{round}(1000 / 2)) = 500$ |

## 5. 到手成本核算公式
$$\text{采购单价 (元/基础销售单元)} = \frac{\text{SKU裸价} \times \text{MOQ} + \text{运费}}{\text{MOQ} \times N}$$
只有当此采购单价 $\le \text{门店零售价} \times 0.50$ 时，该货源方可录入采购系统。
